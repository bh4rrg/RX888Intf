驱动包（v4.194，2026-10-31）
================================================

这是什么
--------
CW Skimmer Server 的 RX888/RX666 设备驱动，下载即用。
不含 CW Skimmer Server 主程序。

包内文件（除本说明外共 3 个）
----------------------------
  RX888Intf.dll        驱动本体（32 位，已内置 RX888 固件）
  RX888Intf.ini        驱动配置
  libwinpthread-1.dll  GCC 线程运行库（驱动唯一的外部 DLL 依赖）

RX888 用户：以上 3 个文件即可开箱即用。

RX666 用户：还需另备 RX666.img（本包不含）——
  从官方 RX666 驱动包中取得，复制到 SkimSrv.exe 同目录。
  RX666 无 flash，每次 USB 上电都由驱动自动下载该固件。

前置条件
--------
1. 已安装 CW Skimmer Server 1.6.x（32 位）
2. 已安装 Cypress FX3 USB 驱动（CyUSB3.sys）。
   判断依据：驱动日志 RX888New.log 中出现设备枚举行
   "Enumerate: boot=1 name='WestBridge'"（bootloader 态，等待固件
   下载，正常）；固件下载成功后设备名为 'FX3'。始终看不到
   Enumerate 行多半是驱动未装好
3. RX888 需接 USB 3.0 口

安装
----
1. 把包内 3 个文件全部复制到 SkimSrv.exe 所在目录
   （RX666 用户再加上 RX666.img）
2. 启动 SkimSrv，在 RX 选择里选中 RX888Intf.dll，Start
3. RX666 每次上电后首次 Start 会先自动下载固件（约几秒），
   随后正常接收

配置说明（RX888Intf.ini）
------------------------
  OutputScale    IQ 输出幅度，直接影响解码门限，勿随意改动。
                 RX666 用 6000；RX888 用 10.0。
  HfAttenuation  HF 前端衰减，仅 0/10/20 三档（单位 dB）。
  UnpauseMode    解码解除暂停策略：0=温和（默认，推荐），1=强制。

常见问题
--------
- 选不到 RX888Intf.dll：确认 3 个文件都在 SkimSrv.exe 同目录
- 日志出现 RX666.img MISSING：把 RX666.img 放入同目录，重新插拔
  USB 再 Start。驱动检测到 RX666 硬件时拒绝改用内置 RX888 固件
  （防止进入无法接收的 'SDR' 假态），因此 RX666.img 是必需文件
- 驱动日志为同目录 RX888New.log（纯文本，累积追加）

注意
----
- 不要向该目录放入任何其他 DLL：SkimSrv 会扫描并加载目录内的
  DLL，外来 DLL 可能导致启动异常甚至崩溃
